# 真实录屏与口播脚本

全部视频无配音；以下可供现场讲解或重新录制配音。截图和视频来自真实本地页面，只有侧栏隐私裁剪，没有改写数据或合成 UI。`capture-evidence.json` 记录实际采集检查；片长以媒体文件为准。

## Overview：40–60 秒

| 时间 | 操作 | 口播 |
|---|---|---|
| 0–10s | 展示总览两个 Case | “渝研研究两个问题：有限客户经理工时怎么分配，订单回款覆盖支出为什么仍会缺现金。” |
| 10–20s | 进入涪陵，再进入供应商 | “事实来自公开资料，客户、订单和参数是合成实验，不代表真实经营效果。” |
| 20–32s | 展示三个角色 | “AI 提议与解释，程序计算，人工确认和决策。” |
| 32–45s | 滚动到已有 Trace | “这是已有真实调用的受控结果，提案仍需要补齐与确认，不能称全自动。” |
| 45–50s | 返回总览 | “继续看案例演示、报告或源码复算。” |

## 自动采集支持

安装前端依赖及 Playwright 浏览器，本地先启动完整平台。使用自己的合成账号文件（email / password），该文件必须位于忽略目录，不加入仓库：

```sh
DEMO_ORIGIN=http://127.0.0.1:3000 ACCOUNT_FILE=/private/local/account.json node scripts/record_portfolio.cjs
FFMPEG=/path/to/ffmpeg python3 scripts/export_media.py
```

脚本执行真实浏览器点击、输入与账本提交，只创建独立合成演示案例；不 mock 网络，不修改 DOM，不发起模型调用。原 WebM 留在被忽略的 `tmp/portfolio-recordings/`，含侧栏，不得公开。导出脚本裁去 256 像素侧栏，保留实际操作顺序；GIF 为概览录像中连续 12 秒，非幻灯片。无需上传浏览器 storage state 或登录信息。
