## 交付检查的范围

`delivery_guard.py` 是操作者配置的中间件。针对能识别的明确文件生成请求，在模型准备结束时检查当前会话已展示的实际文件：非空、非符号链接，且相对本轮开始前的文件快照有变化。未通过时最多继续模型两次；仍失败则返回明确未完成状态。

两次重试上限、提前结束、缺文件、空文件、旧文件和路径处理由单元测试及使用模拟模型的真实 LangChain 图测试覆盖。本轮真实模型任务正常完成，未触发自动重试，因此不宣称已经验证真实模型的恢复成功率。

识别采用有限的中英文词和扩展名规则；复杂输入输出交错语句、未覆盖扩展名不保证识别。显式文件名按 basename 比较，不区分不同子目录中的同名文件。文件变化用大小和修改时间判断，不是内容语义核验。检查不能判断报告事实正确、图片质量或所有需求均满足，也不能替代用户验收。超过 1000 个输出文件时明确停止建立快照。

## 已知限制

联网报告仍需要人工核对；提示词约束不能保证每项表述有依据。默认单 Agent，未开放多租户公网部署，未测吞吐量、长期稳定性或灾难恢复。沙箱需 Docker、联网/图片需要可用模型额度。语音、多 Agent 协同、全自动任务恢复不是本次已验收能力。
