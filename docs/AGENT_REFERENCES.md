# Agent 参考与落实范围

本轮只围绕通用Agent。原选型记录来自2026-10-12固定版本调查，不声称已运行各参考项目的全部最新功能。

| 参考 | 具体借鉴 | 当前落地 | 边界 |
|---|---|---|---|
| CodeFreex | 对话与成果并排、继续修改 | 原Next.js成果预览、文件下载、连续修改 | 非完整复刻应用商店和版本产品体验 |
| Nexus Agent | 文件、来源、图片工具体验 | 真实搜索/网页读取、图片生成与编辑 | 未完整复现视频和任意MCP配置 |
| MiniAgent | 执行反馈、工具配置、有限循环 | 工具进度、用户助手配置、交付有界续跑 | 无多角色编排承诺 |
| DeerFlow | 实际工程底座 | FastAPI/LangGraph/Next.js、沙箱、持久化、用户隔离 | 使用固定提交5b2a135；未启用所有上游能力 |
| GPT Researcher | 检索、阅读来源、报告流程 | 真实工具链和带来源报告 | 没有移植其完整研究编排 |
| Open Deep Research | 可配置任务与评测意识 | 有可复跑验收与失败记录 | 仅参考，未集成其代码 |

本次优先修复实际出现的交付失败并验证完整任务。工具存在、某次任务通过、与其他产品全面对标，是三个不同结论。具体通过/失败只以本轮记录为准。
