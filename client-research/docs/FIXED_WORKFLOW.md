# 固定研究流程与静态演示

本次采用用户授权的备选方案：把作者逐原文核校的研究流程和判断规则固定下来，交付可独立托管的静态 demo。**不宣称模型已经达到 Codex 作者研究水平。**

## 输入、执行与输出

`research_playbook.py`保存5个主体的作者判断、反证、停止条件和访前问题。`data/reference-facts.json`为已核校事实，`data/sources.json`为真实来源快照。`build_demo.py`实际执行主体校验、原文匹配、规范来源去重、Decimal计算和版本打包，生成5个主体8个资料版本及真实构建trace。模型调用为0；这不是新一轮Agent评测。

流程固化为：限定企业与期间 → 选定原始来源 → 对照主体和项目 → 核对日期与期间 → 去重 → 计算 → 应用作者核校判断 → 列出缺失与停止条件 → 比较版本。原Agent、真实模型trace、失败样本保留。本流程复用作者研究结果，不能推广为任意企业自动研究。

当前展示的版本是作者编排的资料可见范围，不是声称历史上曾经生成过这些报告。日发的当前审批阶段可替代，但受理历史保留；秦安的半年数据修正趋势概括，不覆盖全年数据；隆鑫补读结算章节排除错误前提，转载不计新事件。错误假设被明确排除，不伪造过去的模型执行历史。

## 本地运行

在仓库根目录：

```bash
python3 client-research/build_demo.py
python3 -m http.server 8766 --bind 127.0.0.1 --directory client-research/demo
```

打开 http://127.0.0.1:8766 。无API key、数据库或安装步骤。`demo/`目录可作为GitHub Pages发布产物；本次未修改旧Pages部署配置，未发布。不要用file://直接打开，因为浏览器会限制JSON读取。

复核记录保存在浏览器localStorage，按完整证据版本隔离；切换版本不继承签核。导出保留作者原始判断和用户修改/撤回记录，不将修改伪装为公开事实。清理浏览器数据会丢失复核，请导出保存。静态页面不支持任意新URL在线研究，新增资料需先核校事实和规则、重新构建；本地Agent实验入口继续保留。
