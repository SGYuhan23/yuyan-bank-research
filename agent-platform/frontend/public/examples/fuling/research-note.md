# 涪陵2027经营情景计算实验

版本：2026-10-13.v1

## 研究边界

所有客户、余额、定价、风险和产能均为情景假设；不是重庆农商行内部数据。区域公开数据仅用于研究背景，没有校准客户级分布。

本文件是计算实验说明，不是完整区域产业研究或真实支行年度预算。

## 主要发现

以下结论只适用于给定合成组合和参数，不能推导重庆农商行实际收益。人员规模固定为3人。

|策略|正常贡献（万元）|组合压力贡献（万元）|所需工时|产能约束|
|---|---:|---:|---:|---|
|维持组合|69.22|-14.55|2157.59|可覆盖|
|规模增长|87.14|-11.96|2696.99|可覆盖|
|低成本负债|82.43|-4.87|2481.23|可覆盖|
|综合经营|85.19|-5.46|2804.87|可覆盖|
|均衡配置|81.4|-8.32|2481.23|可覆盖|

## 管理解读

1. 规模增长有额外利息，但必须扣除资金缺口FTP及预期损失代理，不能以新增贷款直接等同利润。
2. 低成本负债策略假设存款增长15%、存款定价下降20bp，效果依赖这一假设。真实客户是否接受以及获客成本尚未验证。
3. 综合经营假设手续费增加25%、服务工时增加30%；模型同时记录收入和资源代价。
4. 压力结果为确定性冲击计算，没有统计发生概率，也不是安全保证。
5. 当前产能只是总工时，没有模拟客户经理技能匹配、授信资本与客户集中度约束，不能直接生成真实经营指令。

## 可复核口径

贡献 = 利息收入 − 存款成本 + (存款−贷款)×2% + 手续费 − 贷款×PD×LGD − 人员×18万元。
所有贷款与存款为年平均余额；金额展示四舍五入至0.01万元。源码使用浮点进行研究计算，不用于记账结算。

## 公开证据

涪陵2025年GDP增速6.7%，重庆全市5.3%。这只说明研究背景，不能用作支行增长率。
来源：[2025年各区县GDP增速](https://nyncw.cq.gov.cn/zwxx_161/rdtt/202602/t20260210_15414119_wap.html)；统计期2025，页面发布日期2026-02-09，读取2026-10-13。
