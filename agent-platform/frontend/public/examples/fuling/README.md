# 涪陵计算实验 v1

运行 `python agent-ops/examples/fuling.py`。仅使用Python标准库，模型关闭仍可运行。

本目录是通用Agent的研究素材和确定性工具，不是独立银行Agent。当前案例的计算与网页由工程代码构建；图片示例来自真实Agent运行。没有声称涪陵正式研究报告已经由Agent完成。

## 数据字典

- id：合成客户编号，SYN前缀；sector：四类情景客群，不代表涪陵真实结构。
- loan/deposit：年度平均余额，万元；loan_rate/deposit_rate：年化定价，小数。
- pd/lgd：情景假设的违约概率与违约损失率，用作EL代理；不用于授信审批。
- fee：年度手续费收入，万元；hours：每年客户服务时间，小时。
- contribution：风险调整经营贡献代理，万元；不含税费、资本成本和总部间接费用。
- feasible：客户服务工时是否不超过人数×1000；不代表信贷政策、资本或流动性约束全部满足。

## 完整参数披露

固定种子2027，120户，每四户依次分配制造业/农业食品/商贸服务/居民经营。企业规模采用lognormal(mu=4.3,sigma=0.7)。关系深度均匀分布0.2–0.85，影响存款与手续费；余额随规模变化。贷款定价3.4%–5.2%，存款定价1.9%减关系深度×1.2%，PD 0.8%–3.5%，LGD45%。这些都是实验假设，没有校准为重庆农商行客户分布。

策略参数（贷款倍数/存款倍数/存款成本变化/手续费倍数/服务工时倍数）：

|策略|贷款|存款|存款定价变化|手续费|工时|
|---|---:|---:|---:|---:|---:|
|维持组合|1|1|0|1|1|
|规模增长|1.20|1.03|0|1|1.25|
|低成本负债|1.03|1.15|-20bp|1.06|1.15|
|综合经营|1.08|1.10|-10bp|1.25|1.30|
|均衡配置|1.07|1.08|-7bp|1.15|1.15|

贷款降息为-50bp，存款竞争为+30bp；制造业/农业冲击的对应行业EL倍数2，小微回款压力以商贸服务EL倍数1.7代理，组合压力采用全组合EL倍数1.8并叠加降息与存款竞争。它们不是发生概率或预测置信区间。“小微”与行业不是同一分类，当前代理必须在正式报告前扩展为客户规模维度。

净FTP=(存款−贷款)×2%，人员服务成本=人数×18万元，产能=人数×1000小时。余额不在策略中自动分配到新客户，增长仅为组合倍数，因此尚不能据此决定具体行业投放或具体RM名单。
