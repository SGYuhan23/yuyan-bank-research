# Versioned local casework

CaseRecord/Artifact/Evidence/ToolResult/Recommendation/Review are strict Pydantic schemas. The model selects a NextAction; the controller validates an allowlist and empty planner arguments. Tool parameters are bound from the case. A LangGraph conditional loop executes at most four planning rounds and eight tool invocations, with a 300-second between-node budget. HTTP model timeout is 100 seconds, embedding 60, reputation 8; OCR compilation 90 and execution 20. No automatic network retries (bounded at zero); a new user run is explicit. A call already in flight can extend the between-node budget by its bounded timeout.

Read-only independent calls share a thread pool; extraction executes first when material-dependent. Trusted adapters assign provenance. User claims and OCR never become bank verification. Text, PNG and JPEG supported; PDF extraction is not implemented. macOS Vision is the real OCR adapter; other OS return unavailable, with manual transcription. Source selection filters region and known publication dates; unknown dates remain a limit rather than invented validity. Existing adequacy/source-scoped generation/review retains conflict handling and John case amount containment.

SQLite uses BEGIN IMMEDIATE for optimistic version updates and reviews. Critical edits increment version and clear current evidence. Result acceptance checks current case/version and ownership. Repeated identical review request IDs return the same record; conflicting reuse fails. Rejected results require a new run before acceptance. Revisions are human-authored, checked for evidence ownership, not automatically semantically approved. Export includes old results explicitly marked stale. Local names are not enterprise authentication; bind to localhost only.

New results are stored locally in ignored local/cases.sqlite. User artifacts are never automatically committed or sent to reputation endpoints. Model calls necessarily send selected user text to configured Qwen; use only public/synthetic demonstration data. URL query/path/userinfo are not sent; optional Google Safe Browsing checks origins only, no direct target requests, and not_flagged never means safe. No credentials are logged.

Training client state deterministically releases authored facts. Learner assistance receives visible dialogue only, never latent truth/rubric. Review-only context receives rubric, public sources and transcript; references to turns must match exact learner quotes. Scores remain pending manual review. Natural-language semantic review uses the same model, not a correctness guarantee; deterministic topic matching is diagnostic only.

Graph tools require graph_lab plus explicit synthetic_graph data. No default transaction visibility in case mode. A local version/hash-checked trained model is required for scores. No model artifact means unavailable. Artifact pickle is loaded only from the local application-generated fixed path, never uploaded input. Experimental scores cannot authorize bank operations.

Training start persists a training-mode case with public-source evidence and only the visible authored statement; latent truth stays in the simulator definition. Graph sample persists graph_lab evidence and actual tool results. Each entrypoint returns case/version/run identifiers for export.
