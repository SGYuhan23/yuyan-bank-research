# 面试与演示材料

## 90秒项目介绍

这个项目解决的不是自动判断一笔交易是不是诈骗，而是让使用者面对付款截图、账户变更等材料时，能够有依据地知道下一步核实什么。

我把业务拆成卖方收款、供应商账户变更、此前付款未收到三个场景。它们可能命中同一份指引，但建议适用的对象和条件不同。项目用LangGraph组织受约束工具调用，模型按材料选择检索、提取或比较，程序保存证据、运行过程和版本，再对建议逐条检查来源与适用范围。审核页展示完整风险、建议、追问和限制；人工修订单独保存，案件修改后旧结果失效。

培训部分有18个自编变体，包含正常业务对照，避免把关键词命中当作合格表现。研究附录还实现了两层GraphSAGE：在447账户的合成测试中，平均AP约0.915，比固定邻域树的0.882更高，但在已有结构挑战上降到约0.496。因此我保留树模型作为默认，也不会把合成标签指标说成真实诈骗识别率。

最有价值的发现是，引用正确不代表建议适用，关系结构也不能替代业务目的。这个作品展示的是证据约束、产品闭环和可解释实验，而不是自动授信或交易拦截。

## 五分钟演示脚本

演示前：按照README启动本地服务，使用已有私有Qwen配置。打开根页面。模型返回时间不保证，预留等待；提前打开本轮真实记录作为明确标识的历史备份。不要把截图或保存JSON装成现场推理。

**0:00–0:40：任务和输入。** 角色选择“卖方收款”，输入“对方发来转账凭证，货可以给他了吗？我是卖家，附件是买家发来的文字，尚未核对本人银行实际到账。”创建案件，上传纯文本：“本项目编写的演示材料，非真实交易。买家消息：我已经转账，请今天交货。此文字不是银行到账证明。”说明它是自编材料。

**0:40–1:40：工具执行。** 点击执行，按实际日志讲解已经返回的检索与提取，不预告模型必然选哪些工具。上次真实运行调用guidance、extract、timeline。若服务失败，展示失败状态；切换到保存记录时明确说“以下是历史真实运行4879327f7f344a79b7ccc1921b703345”，打开eval/final-closeout-v1/browser/main-run.json和main-reviewed.png。

**1:40–2:40：完整审核。** 指出风险、处理建议、追问、边界分开；点击依据定位来源和原文。解释截图不等于到账，核心仍是本人网银/手机银行核对本次货款。无追问可以为空。案例输出可能遗漏显式“到账前不交货”的操作句，审核者应依据原文补明；不要把生成成功等同内容合格。修订建议的JSON须保留证据ID、对象、条件，另存记录，不改写原答案。仅作流程展示时备注“演示，不代表交易安全”。

**2:40–3:15：版本失效。** 导出案件，展示原答案、另存修订和结果哈希。修改任务为“更正：买家撤回付款陈述，需要重新研究”，保存后旧审核区域关闭；后台也拒绝旧版本审核。这是本地版本约束，不是企业级审批认证。

**3:15–4:20：研究附录。** 切换交易图实验，说明仅供内部分析角色的合成演练，非客服访问全行数据。显式选GraphSAGE，创建并执行。展示实际graph、score两个工具和10%向上取整名额（本演练34账户取4，不是447账户评测集），展开名单对应交易与待核实问题，记录是否保留核查及理由。此处是确定性工具流程，零LLM规划。

**4:20–5:00：结果与取舍。** 展示四模型对照：AP约0.629/0.882/0.915/0.640；关系信息在原合成分布有帮助，固定邻域已取得主要收益。GraphSAGE需训练、选择验证轮次和维护权重，而结构挑战AP约0.496，不能推断真实业务目的。以保留失败、人工复核和角色边界收束。

## 五个高难度追问

**1. 为什么需要Agent，普通RAG不行吗？**
简单知识问答可以用RAG，不能声称Agent必然更准。本项目额外处理附件、字段变化、版本和不同工具依赖；规划器只能选择允许工具，材料先提取，限制重复调用和预算。图演练任务固定，因此直接确定性执行，不浪费模型规划。历史六任务Agent调用38次模型、单轮基线6次，未证明效率优势。这是按任务选择复杂度。

**2. 引用都正确，为什么还会答错？**
原文存在只说明引文真实。同一章节有改账户和此前未收到付款两个不同条件，引用整章也可能错用建议。程序检查来源片段、证据归属和版本；语义审核检查对象与条件，但同模型会漏判。本轮正常回答没有“诈骗高发”了，却仍未清楚承认已核实；投资追问仍弱化网址可用条件。这些输出不作为已通过样例，最终需要完整人工复核。

**3. 怎么证明不是把正常客户都当骗子？**
18个变体包含正常与异常设定、三档可见线索，复盘区分初始信息和已释放信息。例如正常账户变更已用留档电话确认，不应继续说未核实。关键词只用于定位主题，否定句也会命中，因此不能计分。本轮真实Qwen识别“不用电话、不必核对账户”为incorrect，但其他复盘措辞仍可能过度要求学员复述，并非自动考核系统。

**4. GNN的收益来自图还是参数？有没有泄漏与泛化问题？**
比较节点统计树、固定邻域均值树、两层GraphSAGE及去邻居消息神经网络。整交易群组分割，训练集拟合标准化，验证AP选轮次；三个初始化使用同一数据，不是三个数据集。节点统计本身已有度数，所以不能称无图基线。AP0.629→0.882说明固定邻域已贡献大部分增益，GraphSAGE约再增0.033，但复杂度更高。结构挑战约0.496且此前已观察，不能当新盲测。合法与异常业务目的可能有同样结构，缺失目的时模型无法判断违法。

**5. 怎么迁移到重庆农商行？**
可以迁移的是证据版本管理、角色条件校验、正常业务对照和人工复核设计。不能直接迁移澳大利亚公开指引、合成标签模型或所谓银行效果。实际业务须由银行确认适用制度、数据权限与任务边界，再用授权资料开展独立核对。面试展示现有作品即可，不虚构合作、试点、冻结权限或经营收益。
