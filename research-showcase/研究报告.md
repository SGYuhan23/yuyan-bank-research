# 先理解生意，再安排金融服务
## 涪陵榨菜客户经营与汽车供应商资金周转
研究日期：2026年10月16日　｜　渝研 · 独立个人研究

本报告回答两个具体问题：面对同一条产业链的不同客户，银行本周应该先做哪项工作？当企业收到了客户的付款安排，为什么仍可能没有可用现金？

研究结论
第一，客户经营不宜按企业规模或资金缺口大小直接排序。在本报告的涪陵案例中，经销商的缺口较小，却更早面临付款；合作社需要的是跨采购季的调查；加工企业暂未显示融资需求，应先确认现有结算服务是否真的存在缺口。
第二，资金缺口的金额与持续时间必须一起看。汽车案例中，现金付款改为持有三个月银行承兑汇票，峰值缺口同为56万元，但负余额期由94天变成185天。票据贴现可以缩短后半段的资金占用，却不能解决取得票据之前的采购付款问题。

两项建议
涪陵：本周18小时安排经销商6小时、合作社8小时的核查，留4小时补件；加工企业的6小时结算诊断顺延。排序随资料真实性、付款紧迫性和新增需求变化，不声称银行收益最优。
汽车：先核实付款条件和支付工具，再评估现金到位日期、周转期限及成本。报价、票据签收、融资申请都不能直接替代现金到账。

阅读口径
公开资料用于解释产业机制；三个客户、汽车合同及全部金额、日期和工时均为模拟。2027年是情景发生期，不是已发生业绩。案例不对应任何真实企业账户，也不是银行委托或授信报告。
建议先读第4页的客户经营安排和第6页的收款方案比较，再查对应业务档案。

# 01　为什么选涪陵榨菜？
## 产业事实必须改变经营问题
公开资料能支持的事实不只是“当地有榨菜产业”。企业年报显示，原料采购具有季节性，采购组织涉及合作社与农户；经销结算又存在预付款和部分商业授信。这意味着链条两端的资金时点不必相同。[S1]
企业订单公告将种植订单作为其收购前提。[S2] 企业还披露，已有预约收购系统，但交售意向可能与实际数量出现偏差。[S3] 因而，银行需要核实订单与履约，而不应把“已预约”当成“已经售出”或重复建设已有平台。
重庆人大曾报道约六个月发酵后进入加工的生产实例。[S4] 这为跨月占用提供背景，但不是全部产品的统一工期。本案例的8月交付和9月回款，是特意设定的合同情景，必须在真实工作中逐笔核实。

| 公开依据 | 对研究的影响 | 不能据此推断 |
| 原料采购与生产具有时间差 | 检查收购款与交付回款之间的占用期 | 每家合作社都缺钱或都需要同一期限贷款 |
| 经销渠道存在预付结算 | 检查备货支出、库存消化和下游回款 | 经销商一定能按计划售出 |
| 已有订单和预约系统 | 优先核对现有记录，寻找差异 | 本项目已经接入产业平台 |

本报告选择三种客户原型，不构造120户“代表性样本”。它们用于比较不同服务任务，不代表涪陵客户分布，也不组成一条已经核实的真实交易链。
研究目标是确定下一步服务和调查顺序。银行的收入、成本、信用损失与客户转化率没有足够数据，本报告不计算虚假的综合收益排名。

# 02　三种客户，三种不同任务
## 先把钱从哪里来、何时出去说清楚
以下均为模拟资料，金额单位为万元；期初为2027年1月5日可用资金。测算窗口至9月30日，不计入任何尚未落实的新增融资。

| 原型 | 期初及关键收付 | 测算结果 |
| 收贮加工合作社 F01 | 期初60；1/20支15、2/5支120、2/20支15；8/15收120、9/15收60 | 峰值缺口90；2/5至8/14共191天为负 |
| 榨菜加工企业 F02 | 期初220；1/20收70、2/5支180、2/20支40、3/15收60、7/15支30 | 无负余额；最低可用资金70 |
| 食品经销商 F03 | 期初32；1/12支60、1/25支8；2/10收42、3/10收30 | 峰值缺口36；1/12至2/9共29天为负 |

合作社：资金缺口更大、持续更久。应先核实采购、库存及销售合同是否对应同一批货，销售日期是否与加工周期相容，现有借款是否已覆盖需求。销售合同只是还款来源线索，不是银行担保。
加工企业：在这份收付计划中没有出现资金缺口。下一步应确认采购批次付款与流水对账是否确有未满足需求。没有差错证据、现有服务已经覆盖时，应保留原流程，而不是为了营销新增产品。
经销商：1月12日就需要预付备货。应先看库存是否滞销、销售回款是否可靠，再比较缩减首批采购与周转融资。不能因付款紧急而跳过真实性核查。

这些是不同的经营任务：合作社重在期限与存货，经销商重在备货与动销，加工企业重在结算适配。三者不能用同一个余额乘系数的公式替代。
负余额表示“假定继续执行计划但尚未补足资金”的缺口，并非账户实际可以透支。期末为正也不代表途中能够完成付款，更不等于利润。

# 03　本周18小时，怎么安排？
## 先核实更早到期的付款，再调查跨季占用
本周可用于这三户的专项工时为18小时；三个完整任务合计20小时。工时是本研究的排期假设，不是银行标准工时。以下建议以资料基本可得为前提。

| 安排 | 具体工作与投入 | 交付与停止条件 |
| 先做：经销商，6h | 订单库存2h、回款2h、比较方案1h、复核1h | 给出备货与周转需求清单；订单不实、库存滞销或以新债掩盖逾期时暂停融资建议 |
| 接着做：合作社，8h | 材料2h、存货核验3h、资金测算2h、交接1h | 给出有条件的需求和期限清单；销售无法核实、权属不清或重复融资时暂停 |
| 顺延：加工企业，6h | 流程访谈2h、样本勾稽2h、差异分析1h、建议确认1h | 先确认痛点；现有系统已覆盖或无重复差错时不启动改造 |

选入两项共14小时，余4小时留给补件和异常。加工企业是仍需维护的客户，不是被“淘汰”的客户；延期的是本周专项诊断。
这个选择的机会成本，是暂缓对加工企业结算需求的诊断，并可能错过一项服务机会。由于没有收费、转化率和成本实测，不能把机会成本换算成确定的银行利润损失。

什么变化会推翻排序？
只有10小时：先完成经销商6小时核查，合作社先做2小时订单预检，留2小时处理异常。其余调查排到下周，不能把预检写成完成调查。
经销商订单存疑：暂停其融资建议，投入2小时核验；合作社的8小时核查先推进。真实性优先于紧迫性。
加工企业发生影响付款的对账差错：先确认影响范围并安排定位，必要时顺延合作社非紧急环节。不能只按贷款缺口排序。
合作社全部回款晚14天：本案例峰值缺口仍为90万元，负余额期增至205天。后续融资调查应重新评估期限，而不能只确认“额度够不够”。

# 04　汽车供应商：钱在哪里？
## 120万元订单，现金到位却有不同路径
模拟企业是一家汽车零部件供应商，交易对手设定为符合相关通知主体范围的整车企业。订单总额120万元，预付款24万元已在窗口开始前收到；2027年1月1日期初可用资金35万元已经包含该预付款，不能重复计入。
剩余96万元，模拟合同约定验收合格后30个自然日支付。交货日3月19日、验收日3月20日、开票日3月21日，对应合同付款日4月19日。日期是场景约定，不是行业平均账期。

| 时间 | 业务事项 | 金额与现金含义 |
| 1月15日 | 材料采购付款 | 支出55万元，测算余额从35变为-20 |
| 2月10日 | 人工与外协付款 | 支出18万元，测算余额变为-38 |
| 3月10日 | 能源、运输等付款 | 支出12万元，测算余额变为-50 |
| 4月10日 | 税费及其他到期付款 | 支出6万元，测算余额变为-56 |
| 4月19日或之后 | 剩余货款取得现金 | 取决于支付方式与变现条件 |

这里列的是企业在窗口内的汇总现金计划，不是完整损益表，也不是订单毛利测算。支出6万元是模拟现金安排，未声称按120万元订单推算税额。应用到真实企业前必须补齐其他订单、借款偿还及受限资金。
2026年9月的汽车账款通知分别处理验收、账期、支付方式和贴现成本。[S6] 本报告据此把“按合同付款”和“银行账户已有现金”分开，不把票据签发直接记为现金收入，也不自动判断任何合同合法合规。

# 05　付款方式改变的是占用时间
## 峰值相同，资金压力仍可能相差91天
除剩余96万元的收款方式与日期外，各方案保持期初资金和支出不变；均未假设获得新贷款。以下是确定性计算结果。

| 方案 | 取得现金的日期 | 峰值缺口 | 负余额天数 |
| 现金按期到账 | 4月19日 | 56万元 | 94天 |
| 4月19日收票，持有三个月至到期 | 7月19日 | 56万元 | 185天 |
| 收票次日贴现成功 | 4月20日 | 56万元 | 95天 |
| 现金预计晚14天 | 5月3日 | 56万元 | 108天 |

本例假设4月20日贴现成功，剩余90天，年化2.8%，按实际天数/365计算且无其他费用。成本为6,627.95元，净得953,372.05元。这是情景价格，不是市场报价或银行承诺。
相对持票到期，贴现使本案例的负余额期缩短90天，但不减少此前已经形成的56万元峰值缺口。相对原合同现金付款，贴现方案则多一天等待并承担费用，不能称为“全面改善”。
4月19日前仍须解决采购和运营付款：票据尚未取得时，不能靠未来贴现安排支付1月份材料款。如果前期资金没有落实，企业可能根本无法按计划履约。

# 06　银行应怎样使用这个分析？
## 先分清问题，再选择服务
第一步，核对交易条件。确认交付、验收、发票、支付方式以及争议扣款条款；付款条件尚未满足时，不能把合同日期当成无条件到账日。对方提出改为票据，也不能默认为供应商已同意。
第二步，确认资金是否可用。现金到账需与银行流水核对；票据已收到，需要单独核实承兑主体、到期日、转让限制及真实性。持票并不等于已经具备现金付款能力。
第三步，比较处理方式。合同条件可以协商时，先看调整采购批次、预付款或回款安排是否可行；票据确实可贴现时，再比较净得现金与费用。融资调查还需覆盖企业全口径资金、存量债务和偿债来源。

| 状态 | 在产品里怎样显示 | 是否计入实际现金 |
| 预计 | 依据合同和假设测算未来收付，可切换情景 | 否 |
| 已确认安排 | 双方确认了金额、日期或支付方式，保留材料依据 | 否 |
| 已入账 | 已取得实际银行流水并完成核对 | 是 |

案例中的四条曲线全部属于情景预测；没有真实入账数据。贴现情景是“办理成功后”的条件计算，报价和申请阶段不能自动切换到已入账。票据贴现后，不能在票据到期日再重复增加96万元现金。
结论不是“应当给企业56万元贷款”。56万元只是在列示现金计划与特定假设下的缺口下界；最低安全余额、未列支出、现有融资及压力情景可能改变实际资金安排。
AI可辅助整理问题、提出参数和解释结果。最终金额与日期由程序计算。演示页面提供的是预设分析路径，未把预先编写的说明冒充现场大模型推理。

# 07　哪些结论可靠，哪些仍要验证？
## 产业机制有依据，企业需求仍是假设
本研究的可复核部分包括公开来源、收付清单、计算公式、日期口径和情景差异。它不能验证真实客户意愿、银行收益、授信可得性或方案实施效果。

| 层次 | 本报告中的例子 | 使用限制 |
| 公开事实 | 采购与渠道结算模式；汽车账款管理文件 | 有来源、时间和适用范围；不直接外推全部客户 |
| 研究假设 | 三个客户原型；18小时；120万元订单；2.8%贴现率 | 为比较机制而设；不是访谈、银行数据或市场报价 |
| 程序结果 | 合作社90万元/191天；汽车56万元/94至185天 | 只在对应输入和收付范围内成立 |
| 经营判断 | 优先核查经销商与合作社；先确认现金可用性 | 有条件建议；不是实际银行决策或已实现收益 |

计算口径
每日余额＝期初可用资金＋截至当日列示的累计现金流。峰值缺口＝最低日终余额的相反数与零之间的较大值。负余额天数按自然日计数，现金到账当日若余额已转正则不再计负日。金额以分存储，展示单位再换算为元或万元。
局限与需要补充的材料
企业全口径流水、存量债务、资金受限情况、真实库存、合同履约及客户意愿均未获得。本报告没有估计违约概率、银行风险调整收益或营销转化率。工时与需求经实地核验后，客户排序可能变化。
负余额期只是未补资条件下的测算压力，不代表企业真的连续透支或已经经营失败。报告中的正向期末余额也不能用来证明盈利能力。
判断是否值得实施，必须观察材料能否核实、需求是否存在、可执行方案是否改变付款压力，以及服务成本是否可以接受；不能只看演示曲线是否漂亮。
